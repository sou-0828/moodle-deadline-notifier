# Moodle 未提出課題 Discord 通知

Moodle の「タイムライン」を自動でチェックして、**まだ提出していない課題・小テスト**の締め切りが近づくと Discord に通知します。

- Moodle を使っている大学ならどこでも使えます（ID とパスワードでログインする Moodle に対応）
- 提出済みの課題は通知されません
- 授業ごとに「何日前から」「何時に」通知するか、通知しないかを決められます
- GitHub Actions で動くので、PC やスマホを起動しておく必要はありません
- 料金はかかりません（GitHub の無料枠で動きます）

```
⚠️ 未提出が 2 件あります
・第5回レポート提出
　データベース論
　締切 11/16(月) 23:59・あと約35時間
```

> ⚠️ **非公式ツールです。** どの大学・Moodle とも関係ありません。使う前に、大学の利用規約で自動ログインが禁止されていないか確認し、**自己責任**で使ってください。

## はじめかた（10〜15分くらい）

### 1. 自分用のリポジトリを作る

1. このページ右上の緑色の **「Use this template」→「Create a new repository」** を押す
2. Repository name は好きな名前でOK（例：`my-moodle-notifier`）
3. **必ず「Private」を選ぶ**
4. 「Create repository」を押す

> ❗ Fork は使わないでください。Fork だと公開リポジトリになってしまいます。

### 2. Discord の Webhook URL を取る

1. 通知を受け取りたい Discord サーバーのチャンネルで **歯車マーク（チャンネルの編集）** を押す
2. **連携サービス → ウェブフック → 新しいウェブフック**
3. **「ウェブフックURLをコピー」** を押す

> 自分しかいないサーバーを作って、そこに通知を送るのがおすすめです。

### 3. Moodle の URL を設定する

1. 自分のリポジトリの `config.json` を開き、右上の **鉛筆マーク** を押す
2. `"moodle_url"` の `https://moodle.example.ac.jp` を、自分の大学の Moodle の URL に書き換える
   - ブラウザで Moodle を開いたときのアドレスの、`/my/` や `/course/` より前の部分です
   - 例：`https://moodle.〇〇.ac.jp` や `https://lms.〇〇.ac.jp/moodle`
3. 「Commit changes」を押す

### 4. ID・パスワード・Webhook を登録する

自分のリポジトリで **Settings → Secrets and variables → Actions → New repository secret** を押し、次の3つを登録します。

| Name（そのまま打つ） | Secret（中身） |
|---|---|
| `MOODLE_USERNAME` | Moodle にログインするときのユーザー名 |
| `MOODLE_PASSWORD` | Moodle のパスワード |
| `DISCORD_WEBHOOK_URL` | 2. でコピーした URL |

> Secrets は暗号化されて保存され、あとから自分でも中身を見ることはできません。他の人には見えません。

### 5. 動くか試す

1. リポジトリの **Actions** タブを開く（「I understand…」が出たら有効にする）
2. 左の **「Moodle課題チェック」→ 右の「Run workflow」→「Run workflow」**
3. 1分ほど待って、Discord に通知が来れば成功です

手動実行のときは、時間の設定を無視してすぐに通知します。未提出の課題がなければ何も届きません。試したいときは「Run workflow」の入力欄に `7` などと入れると、7日先までの課題で試せます。

これで完了です。あとは毎時自動でチェックし、設定した時間に通知します。

## 設定を変える（config.json）

リポジトリの `config.json` を開いて、右上の **鉛筆マーク** から編集し、「Commit changes」を押すと次から反映されます。

```json
{
  "moodle_url": "https://moodle.example.ac.jp",
  "default_days": 3,
  "default_hours": [9, 21],
  "courses": {
    "データベース論": { "days": 2, "hours": [21] },
    "英語": 7,
    "体育": "off"
  }
}
```

| 項目 | 意味 |
|---|---|
| `moodle_url` | 自分の大学の Moodle の URL（ブラウザで開いたときのアドレスの、`/my/` などより前の部分） |
| `default_days` | 締め切りの何日前から通知するか（`0.5` なら12時間前） |
| `default_hours` | 何時に通知するか（0〜23）。`[9, 21]` なら 9時と21時 |
| `courses` | 授業ごとの設定（下の表） |

授業ごとの書き方：

| 書き方 | 意味 |
|---|---|
| `"データベース論": 2` | 日数だけ変える（時間は `default_hours`） |
| `"データベース論": { "days": 2, "hours": [21] }` | 日数と時間を変える |
| `"データベース論": { "hours": [7, 12, 21] }` | 時間だけ変える |
| `"データベース論": "off"` | この授業は通知しない |

- 授業名は **一部だけでOK** です（`"データベース論"` と書けば「データベース論（月曜2限）」に当たります）
- 複数の設定に当てはまる場合は、上に書いたものが使われます
- `"off"` は `"` で囲み、数字は囲みません
- 最後の項目のあとに `,` を付けるとエラーになります

## よくある質問・エラー

**「❌ ログインに失敗しました」と届く**
- `config.json` の `moodle_url` が自分の大学の Moodle になっているか確認してください
- `MOODLE_USERNAME` / `MOODLE_PASSWORD` が正しいか確認してください（Moodle のパスワードを変えたら Secrets も更新が必要です）
- 大学のログインが統合認証（別のサイトに飛ぶログイン画面）の場合は使えません

**Secrets の登録で「Failed to add secret」と出る**
- Name の前後にスペースが入っていないか確認し、Name はコピーせず直接打ってみてください

**通知が来ない**
- 未提出で、設定した日数以内に締め切りがある課題がないと通知されません
- 先生が締め切りを設定していない課題はタイムラインに出ないため、通知されません
- GitHub の定期実行は、数分〜十数分ほど遅れることがあります

**お金はかかる？**
- かかりません。非公開リポジトリの GitHub Actions は月2,000分まで無料で、このツールはその半分以下しか使いません（通知しない時間はログインせずにすぐ終わります）

**しばらく通知が来なくなった**
- Actions タブで、ワークフローが無効になっていないか確認してください

## しくみ

1. GitHub Actions が毎時 `check_assignments.py` を実行
2. その時間に通知する授業があれば Moodle にログインし、ダッシュボードの「タイムライン」と同じデータ（提出ボタンが出ている＝未提出のもの）を取得
3. 授業ごとの設定に合うものを Discord の Webhook に送信

パスワードは自分のリポジトリの Secrets にだけ保存され、Moodle 以外には送信されません。
